# Django Article Project

Веб-приложение на Django с функционалом публикаций, системой лайков без перезагрузки страницы (AJAX), поддержкой изображений, переключением темы и аутентификацией пользователей.

## Функционал
- **Лента статей**: просмотр списка всех опубликованных материалов с предпросмотром текста и обложек.
- **Страница статьи**: отдельный детальный просмотр полной версии статьи.
- **Аутентификация**: форма регистрации новых пользователей, входа и безопасного выхода из аккаунта.
- **Лайки на AJAX**: установка и снятие лайков без перезагрузки страницы (сохраняются в профиле пользователя).
- **Личный кабинет**: просмотр всех понравившихся пользователю статей с быстрым переходом к ним.
- **Темы оформления**: поддержка светлой и темной темы с сохранением выбора в `localStorage`.

## Запуск проекта локально

### 1. Клонирование репозитория
```bash
git clone [https://github.com/shoganai228/django-article-project.git](https://github.com/shoganai228/django-article-project.git)
cd django-article-project

```

### 2. Создание и активация виртуального окружения

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate

```

**Windows:**

```cmd
python -m venv venv
venv\Scripts\activate

```

### 3. Установка зависимостей

```bash
pip install django pillow

```

### 4. Применение миграций

```bash
python manage.py migrate

```

### 5. Создание администратора (опционально)

```bash
python manage.py createsuperuser

```

### 6. Запуск сервера

```bash
python manage.py runserver

```

После этого откройте браузер и перейдите по адресу: [http://127.0.0.1:8000/](https://www.google.com/search?q=http://127.0.0.1:8000/)

Панель администратора доступна по адресу: [http://127.0.0.1:8000/admin/](https://www.google.com/search?q=http://127.0.0.1:8000/admin/)
